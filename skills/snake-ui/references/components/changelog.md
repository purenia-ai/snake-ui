# 更新日志

## 0.1.0（2026-08-14）

- 45 个通用组件文档入口，基于 Vue 3 + TypeScript 构建
- 14 个配置驱动的 CMS 页面区块，统一由 `snake-cms` 渲染
- 兼容安卓、iOS、微信小程序、H5 等
- 详尽的文档支持，现代化的演示效果
- easycom 按需引入，精简打包体积

基础组件（10）

- ConfigProvider 全局配置
- Button 按钮
- Icon 图标
