# CMS 组件入口

新项目请进入 [CMS v2 组件总览](/cms/v2/overview)。v2 使用 `{ component: 'v2.*', active, props }`，14 个区块均有独立配置文档。

下面的公共组件卡片主要用于维护 v1 历史页面。v1 已冻结，不再用于新装修配置；旧协议说明见 [v1 旧版兼容](/cms/legacy/overview)。

第一次接入装修页面？请先完成 [CMS v2 快速接入](/cms/getting-started)。
