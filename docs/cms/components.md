# CMS 组件总览

这里汇总 Snake UI 中可由页面装修配置驱动的 CMS 区块，以及负责解析和编排配置的 CMS 容器。CMS 标记描述的是组件能力，不限制使用方式；商品列表、魔方、图片广告等区块也可以按各自 API 在普通页面中独立使用。

公开组件继续使用表达能力的 `snake-*` 名称。只有容器、配置解析和服务注入等 CMS 基础设施使用 `cms` 命名。

第一次接入装修页面？请先完成 [CMS 快速接入](/cms/getting-started)，再根据页面配置选择组件。
