# Snake UI 文档品牌绿焕新设计

## 目标

以 #06D290 作为文档站与手机预览的核心视觉色，形成清爽、克制的科技绿识别。保留现有信息架构、字体、路由、真机比例和响应式布局，不修改组件库公共主题 API。

## 色彩系统

- 主填充色：#06D290
- 悬停色：#05BE83
- 按下色：#04A873
- 可读链接与强调文字：#007A55
- 亮绿填充上的深色前景：#073B2A

亮色模式用薄荷绿软背景、细边框和克制阴影建立层次；暗色模式保留深绿背景，并适度提高品牌色亮度。浏览器 theme-color 同步为核心品牌绿。

## 文档站

VitePress 品牌变量映射到新色阶，并统一首页 Hero、导航、侧栏、按钮、卡片、行内代码、代码块、提示块和键盘聚焦态。亮绿按钮使用深色文字。首页和导航只增加轻量的薄荷氛围，不改变原有布局和字体。

## 手机预览

外壳保持 395px 基准宽度、70.9 / 143.6 比例、灵动岛、iframe 内边距、缩放算法和固定定位规则。材质改为珍珠白到薄荷金属渐变，加入品牌绿边缘反光、柔和投影和 LIVE 状态呼吸效果；暗色模式使用克制的深绿金属外壳。加载与超时状态继续覆盖 iframe 内容区域，并保持清晰的文字与错误色。

## Demo 顶栏

亮色模式采用 #06D290 → #35E7AD 渐变，标题、返回和首页前景统一为 #073B2A，hover 使用半透明深绿，阴影带绿色倾向。暗色模式继续使用深绿渐变和亮薄荷前景。各组件示例及组件库主题变量不做重设计。

## 动效与可访问性

LIVE 呼吸效果只改变透明度与阴影，不影响布局。所有新增动画和过渡均受 prefers-reduced-motion: reduce 约束。链接、按钮与交互控件提供清晰的 :focus-visible 轮廓，亮绿填充统一搭配深色前景。

## 验证

扩充预览结构测试，锁定品牌色阶、主题色、手机外壳、LIVE 动效、Demo 顶栏前景色，以及既有缩放、比例、定位和 iframe 行为。运行 test:preview-structure、test:docs-structure、type-check 和 docs:build，并检查亮色、暗色、减少动态效果和关键视口下的布局。
