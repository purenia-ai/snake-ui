# Snake Tabs 对齐 uView Pro 设计

## 目标

以本地 uView Pro 的 `u-tabs` 为唯一行为基准，重写 `snake-tabs`，解决当前实现与参考组件在布局、滑块定位、滚动和公开接口上的偏差。标签始终保持单行，滚动模式下激活项自动移动至组件中间。

## 实现范围

- 移植 uView Pro `u-tabs` 的模板结构、横向滚动容器和标签布局。
- 移植节点测量、激活项居中、滑块位置计算及首次布局不播放动画的逻辑。
- 对齐 `list`、`current`、`isScroll`、尺寸、颜色、徽标、滑块和自定义样式等 props 的默认值与行为。
- 对齐 `change` 事件：点击当前项不触发，点击其他项仅向父级提交新索引。
- 保留 Snake UI 组件命名、主题变量、工具函数和 TypeScript 风格。
- 同步更新组件演示、文档和契约测试。

## 移除的非参考能力

当前实现中 uView Pro `u-tabs` 不具备的 `scrollable` 别名、禁用项逻辑、键盘导航和额外 `click` 事件不再保留。组件不自行维护父级的业务选中状态，继续通过 `current` 和 `change` 形成受控数据流。

## 布局与数据流

`snake-tabs` 使用始终开启横向能力的 `scroll-view`。`isScroll=false` 时，内部轨道使用 flex 均分标签；`isScroll=true` 时，标签以单行行内块排列并允许左右拖动。组件测量根轨道和每个标签的位置，根据 `current` 计算 `scrollLeft` 与滑块横向位移。

列表变化后重新获取全部标签尺寸；`current` 变化后更新内部活动索引并重新定位。初次完成定位前隐藏滑块，随后恢复配置的过渡动画。

## 验证

- 增加或调整契约测试，锁定 uView Pro 对齐后的 props、事件、单行布局和定位结构。
- 执行 lint、TypeScript 类型检查、完整测试和 H5 构建。
- 按用户要求，不执行微信小程序构建。

## 边界

本次仅修改 tabs 组件及其直接关联的演示、文档和测试，不改动现有未提交的 button 工作区内容，也不顺带重构其他组件。
