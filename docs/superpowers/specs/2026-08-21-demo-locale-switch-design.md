# Snake UI 手机预览中英文切换设计

## 背景

Snake UI 已提供 `zh-CN`、`en-US` 语言包，以及响应式的语言读取、切换、回退和本地持久化能力。当前文档站不需要建设完整英文镜像，但需要补充可直接使用的多语言说明，并让文档中的 H5 手机预览能够切换中英文。

## 目标

- 保持 VitePress 文档导航和正文以中文为主。
- 完善多语言使用文档，覆盖初始化、切换、翻译、回退和自定义语言包。
- 在手机预览公共导航区域提供 `EN / 中文` 切换入口。
- 切换后，当前演示页的标题、说明、控制项、操作按钮、状态文本和示例内容立即更新。
- 语言选择在刷新及演示页跳转后保持一致。
- 不增加新的国际化依赖。

## 非目标

- 不创建 VitePress 英文目录、英文导航或整站双语路由。
- 不翻译组件 API 文档和全部 Markdown 正文。
- 不改变 Snake UI 对外语言 API 的现有语义。
- 不为中英文之外的语言制作内置翻译。

## 方案

复用 Snake UI 已有的 `currentSnakeLocale`、`setSnakeLocale` 和 `snakeTranslate`。演示站增加一个边界清晰的语言适配模块，集中保存演示专用翻译和组件标题映射，并向 Vue 页面提供响应式语言状态、切换动作和文本查询函数。

不引入 `vue-i18n`。组件库已有语言状态和持久化能力，使用第二套运行时会产生重复状态、同步逻辑和额外维护成本。

## 模块边界

### Snake UI 语言底座

继续负责：

- 注册和选择语言包。
- 暴露当前响应式语言。
- 缺失词条按“当前语言 → 中文 → key”回退。
- 将语言选择写入现有本地存储。

本次只验证这些能力，不改变公共接口。

### 演示站语言适配模块

负责：

- 中文演示文案到英文文案的集中映射。
- 组件演示标题的英文映射。
- 将演示配置中的标签、选项、占位符和说明转换为当前语言。
- 暴露 `localeName`、下一语言按钮文案、切换动作和文本查询函数。

翻译缺失时保留原中文，确保演示内容不会显示空白或内部 key。

### 手机预览公共外壳

公共演示页导航栏显示语言切换入口。点击后调用统一切换动作，不直接维护第二份语言状态。首页入口和主题与语言示例页也读取同一个状态，因此页面跳转和刷新后保持一致。

### 演示内容

演示定义通过计算属性本地化，以便语言变化后自动重算。模板中的业务示例文案优先通过集中翻译函数读取；仅与单个组件强绑定、不会复用的短文案可以使用局部计算值，但不在模板内堆积大量中英文三元表达式。

## 数据流

1. 应用初始化 Snake UI 语言底座，并从现有存储恢复语言。
2. 页面通过演示站语言适配模块读取 `currentSnakeLocale`。
3. 用户点击 `EN / 中文`。
4. 适配模块调用 `setSnakeLocale`。
5. 当前语言响应式更新并由底座持久化。
6. 页面标题、演示定义和模板文案自动重新计算。
7. 刷新或跳转后继续读取同一语言选择。

## 异常与回退

- 请求不存在的语言时保持当前语言不变。
- 英文演示翻译缺失时显示中文原文。
- Snake UI 公共词条继续使用现有中文回退规则。
- 存储不可用时仅影响跨刷新保持，不阻止当前会话切换；沿用底座现有告警行为。

## 文档内容

多语言使用文档至少包含：

- 内置语言和默认语言说明。
- 全局初始化示例。
- `useSnakeLocale()` 响应式切换示例。
- `snakeTranslate()` 或 `t()` 的插值示例。
- 自定义语言包注册与局部覆盖示例。
- 当前语言、中文和 key 的回退顺序。
- 语言选择会持久化的说明。
- 指向手机预览“主题与语言”示例的入口。

## 测试与验收

- 现有语言底座测试继续通过。
- 结构测试验证手机预览存在统一语言切换入口，并使用集中适配模块。
- 测试验证核心组件标题、控制项和常见交互文案具有英文映射。
- 测试验证多语言文档包含初始化、切换、自定义语言和回退说明。
- H5 构建成功。
- VitePress 文档构建成功。
- 完整预览构建能在 `docs/.vitepress/dist/h5/` 生成手机预览。

验收时在手机预览中切换为英文，当前页主要文案应立即变为英文；刷新并进入其他组件演示后仍保持英文。切回中文后行为对称。
