# CMS 文档一级专区设计

## 目标

将 CMS 从指南中的子分组提升为独立文档域，让装修业务用户可以沿着接入、数据契约、编辑器对接和组件选择完成完整路径。

## 信息架构

- 顶栏顺序为“指南、组件、CMS、工具”，CMS 入口指向 `/cms/getting-started`。
- CMS 侧边栏分为“开始”“数据与编辑器”“组件参考”。
- 三篇 CMS 指南迁入 `/cms/`，原 `/guide/` 地址保留迁移提示。
- CMS 组件总览复用现有组件卡片，只展示注册表中标记 `cms: true` 的组件；组件 API 仍归属 `/components/`。

## 兼容与验证

本次不修改 Snake UI 运行时或公共 API。结构测试覆盖导航、页面、筛选条件和旧入口，文档构建负责验证页面生成及内部链接。
