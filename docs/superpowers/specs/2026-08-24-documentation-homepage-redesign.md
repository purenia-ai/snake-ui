# Snake UI 文档首页改版设计

## 目标

将当前接近 VitePress 默认模板的文档首页升级为完整的 Snake UI 产品官网首页。页面借鉴 uView Pro 的信息层级和浏览节奏，但保留 Snake UI 自身的商城、CMS 定位以及墨绿与翡翠色品牌视觉，不复制对方的具体素材或实现。

## 范围

本次只改造文档站首页及其必要的主题样式、组件注册和结构测试，不调整指南、组件、工具正文，也不改动 uni-app 演示应用页面。

## 页面结构

首页按以下顺序组织：

1. 品牌首屏：左侧展示品牌定位、能力说明、项目徽章和四个主要入口；右侧展示带光晕、环形轨迹与悬浮能力标签的 Snake 品牌图形。
2. 数据概览：展示可从仓库确认的组件、工具、CMS 模块和支持平台等数据，不展示无法验证的下载量、访问量或合作伙伴数量。
3. 核心能力：以卡片矩阵介绍 CMS 驱动、组件契约、主题与暗黑模式、国际化、多端兼容、工具能力等特性。
4. 热门入口：展示常用组件与工具入口，卡片直接链接到对应文档。
5. 在线演示：说明文档与 H5 示例联动方式，并提供进入在线演示和组件文档的行动按钮。
6. 生态入口：提供指南、组件、工具及代码仓库等后续路径；沿用站点全局页脚。

## 视觉设计

- 使用现有 Snake UI 品牌变量，以深墨绿、翡翠绿和中性色为主。
- 首屏使用柔和径向渐变、品牌图形光晕和低强度环形动画，形成与 uView Pro 类似的视觉重心。
- 内容卡片采用轻玻璃质感、细边框、圆角和克制阴影；悬浮时轻微上移并增强边框颜色。
- 保持文本层级清晰，避免用大量装饰抢占文档入口的注意力。
- 完整支持浅色、暗黑模式和窄屏单列布局。
- 遵循 `prefers-reduced-motion`，用户要求减少动态效果时关闭非必要动画。

## 实现结构

- 新增独立 Vue 首页组件承载页面结构和静态数据，使用 Vue 3 `<script setup lang="ts">`。
- `docs/index.md` 仅负责选择自定义首页布局和提供页面元信息，不堆叠大段 HTML。
- 在现有 VitePress 主题入口注册首页组件，复用当前主题变量与导航配置。
- 首页专属样式与文档正文、手机预览样式使用明确的类名前缀隔离，避免影响其他页面。
- 不新增第三方依赖；图标优先使用内联 SVG 或现有品牌资源。

## 内容与数据约束

- 所有数字必须由当前仓库配置或清单推导，并集中定义，避免散落在模板中。
- 不虚构下载量、用户数、访问量、合作伙伴和生态规模。
- 链接使用站内路径时兼容 VitePress 的 `base` 配置；外部在线文档地址以 `https://m.puresnake.com/snake-ui/` 为准。
- 首页文案突出“面向 uni-app 商城与 CMS 场景的组件库”，不泛化为通用 UI 框架。

## 响应式与可访问性

- 桌面端首屏采用左右双栏，内容区域保持合理最大宽度。
- 平板和手机端改为单栏，品牌图形位于主要行动按钮之后，卡片网格按可用宽度降列。
- 所有可点击卡片与按钮提供可见焦点样式和明确文本。
- 装饰图形不进入无障碍阅读顺序；重要图标提供文本语义。
- 颜色对比和交互状态同时兼顾浅色与暗黑主题。

## 验证

- 增加首页结构回归测试，确认核心区块、主要链接、品牌文案和官方地址存在。
- 运行文档站构建，验证 SSR/SSG 阶段没有浏览器 API 或 hydration 问题。
- 运行 Prettier 检查与 `git diff --check`。
- 人工检查桌面、移动端、浅色、暗黑模式和减少动画设置下的布局。

## 非目标

- 不复制 uView Pro 的源代码、品牌素材、文案或统计数据。
- 不在本次改造中新增博客、后端统计、下载量接口或合作伙伴管理。
- 不修改演示应用的底部导航与页面目录结构。
