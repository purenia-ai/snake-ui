# Button 组件与演示页优化设计

## 目标

参考 uView Pro Button 页面清晰的能力分组与展示密度，优化 Snake UI 的按钮组件、组件演示页和使用文档，同时保持现有公开属性及默认行为兼容。

## 范围

- 优化 `snake-button` 的视觉规格、交互反馈和水波纹效果。
- 重构 Button 演示内容，覆盖主题、镂空、尺寸、形状、状态、图标、自定义颜色与水波纹。
- 同步更新 Button 文档、公开类型注释和针对性测试。
- 不复制 uView Pro 源码，不改动其他组件，不引入新依赖，不替换现有主题变量体系。

## 组件设计

### 兼容性

保留现有 Props、Events、Slots 及默认值。现有调用无需迁移；优化仅影响视觉细节与水波纹起点。继续以 uni-app 原生 `button` 作为根节点，保留表单和小程序开放能力透传。

### 视觉规格

- 使用现有 `--snake-*` 主题变量表达颜色、圆角和动效。
- 统一各尺寸的高度、横向内边距、字号与图标间距。
- 全宽尺寸和内容宽度尺寸保持当前语义：`large`、`default` 默认占满容器，`medium`、`small`、`mini` 随内容收缩。
- `square` 使用主题圆角，`circle` 使用胶囊圆角。
- 镂空、禁用、加载、按压状态保持足够的视觉区分；加载和禁用状态不触发业务点击及开放能力。

### 水波纹

水波纹根据触摸或点击坐标定位起点，并按按钮实际边界计算覆盖半径。无法取得坐标或尺寸时回退到中心扩散。动画结束后清理状态和计时器，组件卸载时同步清理，避免残留异步任务。

### 可维护性

派生类名和样式使用 `computed`，交互状态使用局部 `ref`。事件契约继续通过 `SnakeButtonEmits` 声明；公共类型与运行时 Props 保持一致，并用中文注释说明用途、单位和平台限制。

## 演示页布局

演示内容按以下顺序分组：

1. 按钮主题：default、primary、success、info、warning、error。
2. 镂空按钮：常用主题的 `plain` 对照。
3. 按钮尺寸：large、default、medium、small、mini。
4. 按钮形状：方形与胶囊形。
5. 按钮状态：普通、禁用、加载及自定义加载文字。
6. 图标按钮：图标与文字组合。
7. 自定义颜色：通过 `color` 展示品牌色能力。
8. 水波纹：展示默认及自定义水波纹颜色。

每组采用适合移动端的卡片或区块布局：全宽按钮纵向排列，小尺寸按钮自动换行；示例间距统一，避免按钮贴边或不同分组节奏不一致。

## 文档设计

文档与演示页使用相同的信息顺序。每项能力提供最小可复制示例，并明确尺寸语义、加载/禁用点击行为、水波纹行为及跨平台注意事项。API 表保留完整属性、事件和插槽说明。

## 验证

- 增补或更新按钮组件契约测试，覆盖 Props 默认值、禁用/加载点击拦截和水波纹关键行为。
- 运行相关测试、TypeScript 类型检查和 lint。
- 运行 H5 构建，确认 SFC、样式与 uni-app 模板编译正常。
- 检查文档构建，确认 Markdown 示例和表格正常渲染。

## 验收标准

- 现有 Button 用法无需修改即可工作。
- 演示页能清楚查看所有主要能力，在移动端无溢出和拥挤布局。
- 水波纹从用户操作位置扩散，并能覆盖整个按钮。
- 禁用与加载状态不会触发 `click`。
- 类型检查、相关测试、H5 构建和文档构建通过。
