# Snake UI Icon 组件与示例页优化设计

## 目标

参考 uView Pro Icon 页面成熟的信息组织方式，提升 Snake UI Icon 示例页的浏览和使用效率，同时补齐现有 `SnakeIcon` 标签布局能力。整体保持 Snake UI 当前克制、少色、白底的视觉方向，不复制未包含在自有 iconfont 中的 uView Pro 图标。

## 范围

本次包含：

- 优化手机预览中的 Icon 示例内容和图标宫格。
- 只展示 Snake UI 当前真实可用的字体图标和兼容图标名称。
- 提供图标选择反馈和名称展示，方便开发者识别与复制。
- 扩展示例参数：尺寸、颜色、加粗、标签文字和标签位置。
- 补齐 `SnakeIcon` 的 `left`、`right`、`top`、`bottom` 四种标签方向布局。
- 更新必要的类型、文档和自动化测试。

本次不包含：

- 引入或复制 uView Pro 的完整 iconfont。
- 新增外部依赖。
- 重做其他组件示例页或文档站整体布局。

## 页面设计

Icon 示例页使用白色背景和紧凑宫格。每个图标单元由图标和名称组成，以细分隔线或轻边界划分，不使用大面积彩色卡片。选中项仅使用品牌绿进行小范围强调，其他图标保持中性色。

示例区分为两个层次：

1. 顶部预览：展示当前选中图标，并实时响应尺寸、颜色、加粗及标签参数。
2. 图标集：展示可用字体图标宫格，点击后切换顶部预览并显示准确名称。

宫格在手机端保持至少三列，名称过长时单行省略，点击区域满足移动端操作尺寸。

## 组件行为

`SnakeIcon` 保留字体图标、图片图标、自定义前缀、点击事件和事件阻止等现有能力。标签方向统一为：

- `right`：图标在左、标签在右。
- `left`：标签在左、图标在右。
- `bottom`：图标在上、标签在下。
- `top`：标签在上、图标在下。

`space` 始终表示图标与标签之间的距离，并按实际方向设置对应外边距。无标签时不产生额外间距。

## 数据与边界

图标清单维护在演示层，并与 `iconfont.css` 中的 `sicon-*` 类名保持一致。演示不声明字体文件中不存在的图标。兼容字符图标仍可由组件解析，但图标集优先展示自有字体图标，以保证视觉一致性。

颜色选项保持精简：品牌绿、正文深色和中性灰。参数变化仅影响顶部预览和图标集的图标本身，不给宫格单元增加多余背景色。

## 验证

- 组件契约测试覆盖内置 iconfont 与标签四方向布局。
- 预览结构测试确认图标宫格、选中交互和参数配置存在。
- 文档测试确保公开属性与示例一致。
- 运行相关 lint、格式检查和 H5 构建。
- 在本地预览中检查手机宽度下的宫格密度、文字截断、点击反馈和标签方向。
