# Snake UI 指南信息架构调整设计

## 目标

在不移动现有页面路由、不改组件 API、不过度复制工具文档的前提下，改善指南侧边栏分类和文章入口，让基础接入、通用配置、CMS 专属能力及迁移排错形成清晰的阅读路径。

## 信息架构

指南侧边栏调整为四组：

1. “开始”：介绍、快速开始、运行环境与能力边界、设计理念。
2. “配置与自定义”：全局配置总览、国际化、多主题与暗黑模式、主题生成器、自定义样式。
3. “商城与 CMS”：CMS 快速接入、组件数据约定、装修编辑器数据对接。
4. “迁移与排错”：从 uView Pro 迁移、常见问题。

本次只调整 VitePress 逻辑分组，保留现有 `/guide/*.html` 路由，避免引入重定向和外部链接失效风险。

## 页面调整

### 全局配置总览

保留 `docs/guide/foundation.md` 文件与 `/guide/foundation` 路由，将标题从“全局配置与底座”改为“全局配置总览”。国际化章节缩减为能力摘要并链接独立指南；工具入口直接链接 `/tools/intro`，不再主动经过旧兼容页 `/guide/tools`。

### 国际化

新增 `docs/guide/internationalization.md`，覆盖：

- 内置语言和回退顺序；
- 应用入口配置；
- 运行时切换与组合式函数；
- 添加或局部覆盖语言包；
- 与 `vue-i18n` 等业务国际化方案协同；
- 持久化、平台行为和 API 摘要；
- 指向 `/tools/use-locale` 的详细工具 API。

示例仅使用仓库现有的 Snake UI 公共 API，不引入新接口。

### 设计理念

新增 `docs/guide/design-principles.md`，解释 uni-app Vue 3 边界、基础组件与业务服务分离、CMS 数据适配边界、渐进式 uView Pro 迁移和多端验证原则。

### 自定义样式

新增 `docs/guide/custom-style.md`，说明样式入口、CSS 变量、局部样式、`customStyle`、Config Provider 与暗色适配。该页以使用决策为主，具体组件属性继续以组件 API 文档为准。

### 现有页面入口

更新介绍、快速开始、运行环境、主题及工具相关页面中的导航文案和链接，使其指向新的独立页面与分组。保留 `docs/guide/tools.md` 作为旧链接兼容页，不放回侧边栏。

## 不在范围内

- 不移动现有 Markdown 到物理子目录。
- 不修改组件、主题或国际化运行时代码。
- 不新增依赖。
- 不重写 CMS 长文或组件 API 文档。
- 不删除旧路由兼容页。

## 验证

1. 扩充 `scripts/docs-structure.test.mjs`，校验新的侧边栏分组、页面入口和旧工具页兼容约束。
2. 运行 `npm run test:docs-structure`。
3. 运行 `npm run docs:build`，确认页面、内部链接与自定义组件均可构建。
4. 检查 Git diff，确保没有生成产物或无关文件进入改动。
