# Snake UI 示例应用总览与参数配置设计

## 目标

参考 uView-Pro 的组件总览与详情页体验，统一 Snake UI 在 H5、微信小程序和 App 中的示例应用。用户通过语义分类浏览 32 个公开组件，并在详情页实时修改代表性参数。

## 信息架构

组件总览按基础、展示、反馈与浮层、导航与布局、CMS 内容、CMS 营销、商品业务分组。`componentsA` 与 `componentsB` 只承担路由目录和分包职责，不显示为用户分类。CMS 组件在卡片和详情标题中显示 CMS 标识。

## 详情页

详情页采用统一的标题说明、演示效果和参数配置结构。普通组件直接绑定公开 props；只接收 `datas` 的 CMS 组件通过演示场景数据映射参数；弹窗、遮罩、吸顶等特殊组件保留专属模板和事件。

参数控件只使用 uni-app 原生组件和 Snake UI 自有组件，支持选项、开关、滑块和文本输入。页面保持自然滚动，不使用整体缩放、固定内容高度或裁剪。

## 兼容性

不修改 Snake UI 公共 props、事件、安装方式或运行时适配器。现有 32 个文档预览 URL 保持不变。H5、微信小程序和 App 共用同一套示例配置与页面结构。

## 验收

32 个路由均出现在总览、具备演示配置并能打开详情页；搜索覆盖名称、说明、分类和 CMS 标记；主要参数可实时改变真实组件；H5、微信小程序和 App 构建通过；视口型组件不被手机预览裁剪。
