# Upload 演示页增强设计

## 背景

`snake-upload` 已经支持图片、视频、普通文件、网格与列表模式、手动上传、自定义上传请求、自定义按钮和自定义文件列表，但当前演示页只展示 OSS 适配器、最大数量控制和一个空列表，无法直观体现组件能力。

本次只增强 `src/pages/componentsA/upload/index.vue`，不修改 `snake-upload` 的公共 API、内部上传逻辑或文档契约。

## 页面结构

演示页继续使用项目现有的 `DemoPage`、`DemoSection` 和 `DemoControlPanel`，按以下顺序展示：

1. 图片上传：网格模式，带一个预置成功文件，使用模拟自定义上传请求。
2. 参数配置：控制图片示例的最大数量和图片形状。
3. 文件上传：列表模式，展示文件名、大小及预置文件。
4. 视频上传：展示视频类型、数量及最长时长限制。
5. 手动上传：关闭自动上传，提供开始上传和清空列表操作。
6. 自定义上传按钮：通过 `addBtn` 插槽展示品牌化选择入口。
7. 自定义文件列表：通过 `file` 插槽展示文件图标、名称、大小、状态和删除操作。

页面标题和说明强调组件既支持普通接口，也支持 OSS 等自定义上传适配器。

## 状态与数据流

每个演示区域使用独立的 `ref<SnakeUploadFileItem[]>`，避免一个示例的选择、上传或删除影响其他示例。

所有可交互示例复用一个本地模拟 `SnakeUploadRequest`。适配器通过 `onProgress` 分阶段更新进度并返回本地文件 URL，不访问真实服务。手动上传区域通过组件 ref 调用 `upload()` 和 `clear()`。

自定义列表直接消费 `file` 插槽提供的列表；删除操作通过组件公开的 `remove(index)` 完成，确保示例同时演示公开方法。

## 交互与视觉

- 示例保持 Snake UI 当前卡片和主题变量体系，不复制 uView Pro 的页面容器样式。
- 自定义上传入口使用虚线边框、图标和简短提示文字。
- 自定义文件行包含文件类型图标、截断文件名、格式化大小、上传状态及删除入口。
- 操作按钮使用现有 `snake-button`，提供禁用状态，防止空列表上传。
- 页面使用 rpx 和主题变量，兼容 H5、App 与小程序布局。

## 错误处理

模拟上传保持确定性成功，避免演示页面随机失败。组件自身的大小、数量、选择失败及上传失败处理仍由既有实现负责。本次不新增 toast 依赖；手动上传状态直接通过文件列表进度呈现。

## 验证

- 运行 Upload 组件契约测试，确认示例改动没有破坏公开能力。
- 运行项目 TypeScript/Vue 类型检查或现有等价检查。
- 运行与页面相关的 lint/格式检查。
- 检查生产构建，确认模板、插槽和跨平台编译通过。

## 非目标

- 不连接真实上传服务器或 OSS。
- 不增加、删除或重命名 `snake-upload` 的 props、events、slots、methods。
- 不修改其他组件演示页或重构通用演示框架。
