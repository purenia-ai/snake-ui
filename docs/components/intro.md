# 组件总览

Snake UI 提供覆盖基础交互、表单和商城装修场景的组件。输入组件英文名、中文名或文档路径，即时定位所需能力。

第一次使用 Snake UI？请依次完成[安装](/components/install)、[配置](/components/setting)和[快速上手](/components/quickstart)，再从下方选择组件。

页面装修能力统一进入 [CMS 组件总览](/cms/overview)；CMS 区块由 `<snake-cms>` 按配置渲染，不作为独立 easycom 组件出现在下方目录。
