# NoNetwork 无网络提示

无网络提示组件，无需任何配置，引入即可。自动监听网络状态，断网时全屏展示提示，并支持重试。

## 平台兼容性

|  H5  | 微信小程序 | App  |
| :--: | :--------: | :--: |
| 支持 |    支持    | 支持 |

## 基础用法

```vue
<snake-no-network />
```

组件在线时自动隐藏；断网时全屏展示图片、提示语与重试按钮。点击重试会重新检测网络，
未恢复时提示无网络连接，恢复后提示已连接，并触发 `retry` 事件。

## API

### Props

| 参数     | 说明                           | 类型               | 默认值          |
| -------- | ------------------------------ | ------------------ | --------------- |
| `tips`   | 没有网络时的提示语             | `string`           | 语言包默认值    |
| `zIndex` | 组件层级值                     | `number \| string` | `10080`         |
| `image`  | 图片提示，图片地址或 base64    | `string`           | 内置提示图      |

### Events

| 事件名  | 触发时机             | 参数 |
| ------- | -------------------- | ---- |
| `retry` | 点击重试按钮         | -    |

### Methods

| 方法名  | 说明                           |
| ------- | ------------------------------ |
| `retry` | 重新检查网络并触发 retry 事件  |
