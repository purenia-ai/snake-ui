# 介绍

Snake UI 是面向 **uni-app Vue 3** 的移动商城与 CMS 组件库。它既提供按钮、弹层、表单等基础组件，也提供商品、优惠券、装修页面渲染等业务组件。

如果你只需要基础组件，安装插件、引入样式并配置 easycom 即可；只有使用 CMS 业务能力时，才需要注入请求、缓存或业务服务。

## 适合什么项目

- 使用 uni-app Vue 3 开发 H5、小程序或 App。
- 需要统一的商城基础组件、主题和国际化能力。
- 后端保存页面装修 JSON，客户端需要按配置渲染页面。
- 正在从 uView Pro 迁移，希望逐步替换已覆盖的组件和工具。

Snake UI 不是普通 Vue Web 组件库，也不负责提供后台装修编辑器、商品接口或外链承载页。这些能力由宿主项目或 SankeEditor 提供。

## 核心能力

| 能力     | 说明                                                           |
| -------- | -------------------------------------------------------------- |
| 基础组件 | 按钮、图标、图片、弹层、表单、轮播、索引列表等                 |
| 商城组件 | 商品列表、优惠券、筛选、活动、营销展示等                       |
| CMS 渲染 | 根据 `pageComponents` 分发组件，支持别名、数据规范化和扩展插槽 |
| 全局底座 | 主题、暗色模式、国际化、HTTP、路由和常用工具                   |
| 多端运行 | 基于 uni-app 内置组件与 API，具体能力受目标平台限制            |

## 使用边界

::: warning 兼容范围
Snake UI 要求 Vue 3 和 uni-app 运行时。仓库中的目标平台均可编译，但每个端的完整兼容程度仍应以业务项目实测为准。
:::

- 基础组件不依赖 uView Pro，也不需要 CMS 适配器。
- 商品、优惠券和外链等业务行为需要宿主提供对应服务。
- `datas` 表描述组件实际读取的配置字段，不等同于后端完整响应协议。
- 从 uView Pro 迁移属于已覆盖能力的兼容，不承诺复刻全部历史属性。
